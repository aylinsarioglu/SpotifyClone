# Spotify Clone

Spotify mobil uygulamasının temel ekranlarını ve uygulama yapısını taklit eden bir React Native projesi.

Bu proje, müzik uygulamalarında kullanılan UI yapıları, state yönetimi ve navigasyon mantığını göstermek amacıyla geliştirilmiştir.

## Screens
- Home Screen
- Search Screen
- Library Screen

## Features
- Spotify benzeri kullanıcı arayüzü
- Component bazlı mimari
- Context API ile state yönetimi
- Navigasyon yapısı
- Yardımcı fonksiyonlar (utils)
- Temiz ve ölçeklenebilir klasör yapısı

## Tech Stack
- React Native
- JavaScript
- Expo
- React Navigation
- Context API

## Project Structure
- `src/screens` – Uygulama ekranları
- `src/components` – Tekrar kullanılabilir bileşenler
- `src/context` – Global state yönetimi
- `src/utils` – Yardımcı fonksiyonlar
- `src/navigation` – Navigasyon yapısı
